Local AI Developer Tools

LM Studio is the friendliest way to run an AI model on your own computer. You install it like any other app, search for a model inside it, click download and start chatting. The part nobody explains well is the middle: which model to pick, what the sliders in the load dialog mean, and why a model that "should" fit your computer runs like molasses. This guide covers those parts, in the order you'll meet them.

How do you set up LM Studio?

Download LM Studio from lmstudio.ai and run the installer. Open the app, go to the model search tab, download a model that shows it fits your hardware, then open the Chat tab, pick the model and load it. Keep GPU offload at maximum and leave context length moderate. You can then chat or start the local server.

🚀 Quick Start: Install, search for a small model (around 3 to 8 billion parameters), download a 4-bit version, load it with GPU offload at max, and say hello. If that works, everything else in this guide is optional tuning.

Before you download: will it fit?

Model size is the first decision, and the quickest way to avoid a bad one is to estimate memory before you download. The tool below uses a rule of thumb: the model's weights take roughly parameters times bits per weight divided by eight, plus room for the context and some overhead.

Step 1: Install

Platform What to do Notes
Windows Run the setup file from lmstudio.ai Installs under your user folder, so admin rights usually aren't needed
macOS Open the downloaded app and move it to Applications Apple Silicon uses its GPU automatically
Linux Use the AppImage Make it executable first

On first launch you'll get a welcome screen and a nudge to download a model. You can skip it and look around, but there's no reason to.

Step 2: Check what LM Studio sees

Open the settings and look at the hardware section. LM Studio lists your processor, system RAM and every graphics card it finds. If your GPU isn't listed, update your graphics drivers before doing anything else. An undetected GPU is the number one reason a setup runs slowly.

On a laptop with two graphics chips, make sure the app uses the stronger one. Windows has a graphics settings page where you can assign an app to the high-performance GPU.

Step 3: Download a first model

Open the search tab and type a model family. Each result shows file sizes for different compression levels, called quantizations. Many models also show a small fit indicator. A green "full GPU offload possible" badge means the whole model should sit in your video memory, which is the fast case.

Quantization Quality Size When to pick it
Q4_K_M Good Smallest of these Your default
Q6_K Better Larger You have spare memory
Q8_0 Very close to full Large Small models where quality matters
F16 Original Biggest Rarely on a home computer

My advice: start with Q4_K_M. The quality difference between Q4 and Q6 is small for chat, and the speed difference is easy to feel.

⚠️ Common Mistake: Downloading the biggest model that technically fits. A model that uses 95 percent of your memory leaves nothing for the context, and everything slows to a crawl. Aim for about 70 to 80 percent.

Step 4: Load it and set the sliders

Go to the Chat tab, click the model loader at the top, and pick your download. A dialog appears with three things worth understanding.

  • GPU offload. This is how many layers of the model run on your graphics card instead of the processor. Max is almost always right when the model fits. If you see an out-of-memory error, lower it a few notches.
  • Context length. This is how much text the model can keep in mind. Older write-ups mention a 4,096 default, and recent versions may suggest more. Longer context costs memory, so resist the urge to drag it to the maximum. Set it to what you actually need, such as 8,000 for normal chat.
  • Estimated memory. LM Studio shows how much memory the load will use. If it exceeds your free memory, change the model, the quantization or the context.

Step 5: Chat, then adjust

Say something short and watch the speed. If words trickle out one at a time, the model is probably running on your processor instead of the graphics card. Check that GPU offload is at max and that the card was detected in step 2.

The system prompt box is the place for standing instructions, like "answer in plain English and keep it short." Keep it brief. A long system prompt eats context. If you want a structure for longer instructions, the Claude master prompt template translates well to local models, though smaller ones follow fewer rules at once.

Step 6: Developer mode and the local server

Open settings and switch on Developer Mode. It exposes more load parameters and the server controls. Then open the Developer tab (or the local server tab in some versions), pick the model, and click Start Server. By default it listens on port 1234 and speaks an OpenAI-style API, so tools built for that format can talk to it.

Test it:

# pip install openai
from openai import OpenAI

client = OpenAI(base_url="http://localhost:1234/v1", api_key="not-needed")

reply = client.chat.completions.create(
    model="local-model",   # use the identifier shown in LM Studio
    messages=[{"role": "user", "content": "Say hello in five words."}],
)
print(reply.choices[0].message.content)

If you get a "model not found" style error, the usual cause is that no model is loaded in the server view. Load one, start the server again and retry.

The same trick works with other tools: point the base URL at your computer instead of a cloud service. That's also how you'd swap in a hosted free tier later, such as the one in the Groq API free limits guide, by changing the base URL and key.

Troubleshooting

Symptom Likely cause Fix
Model loads but runs slowly GPU not used Update drivers, set offload to max
Out of memory on load Model plus context too big Smaller model, lower quantization or shorter context
GPU not detected Old driver or unsupported card Update the driver; check the hardware panel
Server says model not found No model loaded Load a model, restart the server
Answers get dumb in long chats Context filled Start a new chat or raise context carefully
Download stalls Network interruption Retry; downloads resume
