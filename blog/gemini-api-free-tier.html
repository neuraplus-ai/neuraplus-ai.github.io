Ask five websites what the Gemini API free tier allows and you'll get five different answers. That isn't because they're careless. Google changed the limits several times over the past year, stopped printing a simple per-model table in its documentation, and moved some models in and out of the free tier. This guide tells you what's reliably true, what's disputed, and where to look for the number your own project actually gets.

Is the Gemini API free?

Yes. The Gemini API has a free tier that isn't a trial and doesn't expire. You create a key in Google AI Studio, and eligible models are free within rate limits for requests per minute, tokens per minute and requests per day. Limits apply per Google Cloud project, and your exact numbers appear in AI Studio.

🚀 Quick Start

Open Google AI Studio, create an API key, and check your project's live limits in the rate limit view. Use a Flash or Flash-Lite model first, since those are the models free-tier guides agree on.

Why the numbers you read online don't match

Third-party tables circulate wildly different values: some list 15 requests per minute and 1,500 per day for Flash, others quote 5 to 15 requests per minute and 100 to 1,000 per day depending on model. Reddit users reported sharp cuts in late 2025, and some figures from that period stuck around in blog posts long after they changed.

🔁 A pattern worth learning: Free-tier limits are a moving target. Treat any article's numbers, including this one, as a snapshot, and check AI Studio before you design anything around a specific cap.

How Gemini free-tier limits work

Three measures matter, and a fourth shows up for image models.

RPM
Requests / Minute
How many API calls you can make in any 60-second window.
A tight loop can hit it in seconds
TPM
Tokens / Minute
Total input + output tokens per minute, the real ceiling for long prompts.
Long prompts use it before RPM matters
RPD
Requests / Day
Total calls in a 24-hour window, reset at midnight Pacific time.
Resets at midnight Pacific, not your timezone
IPM
Images / Minute
Separate cap for image-generation models only.
Only for image models, not text

🔒 Two hard rules: First, limits are enforced per project, not per key, so creating a second key in the same project gets you nothing. Second, daily limits reset at midnight Pacific time, not at midnight where you live, which surprises people in other time zones.

The privacy catch you shouldn't skip

On the free tier, Google's terms allow it to use your inputs and outputs to improve its products, and human reviewers may read them. That's the price of free. If you're sending customer data, private documents or anything you wouldn't want reviewed, don't use the free tier for it. A paid tier changes that arrangement, so read the current terms on Google's API terms page before you decide.

Privacy Catch

Common mistake: Prototyping with real customer data on the free tier "just to test." Use fake or public data until you've confirmed the terms that apply to your project. Human reviewers may read your inputs and outputs.

Free grounding allowance

Gemini 3 models include an allowance for Google Search grounding, reported at 5,000 free search-grounded prompts per month shared across those models, with a per-request charge after that. Treat this as a reported figure, and verify it on the pricing page before you rely on it.

Quick start code

# pip install google-genai
from google import genai

client = genai.Client(api_key="YOUR_AI_STUDIO_KEY")

response = client.models.generate_content(
    model="MODEL_ID_FROM_AI_STUDIO",   # copy a Flash model ID from the console
    contents="Explain rate limits in two sentences.",
)
print(response.text)

⚠️ Model ID warning: Replace the model ID with a current one from AI Studio's model list. Old tutorials often name retired models, and the 2.5 line shuts down October 16, 2026.

Handling 429 errors

A 429 means you've hit a limit. Wait and retry, and if the daily cap is gone, wait for the reset.

# Exponential backoff for 429 errors
import time

def ask(client, prompt, model, retries=4):
    for attempt in range(retries):
        try:
            return client.models.generate_content(model=model, contents=prompt)
        except Exception as e:
            if "429" in str(e) and attempt < retries - 1:
                time.sleep(2 ** attempt)
                continue
            raise

Backoff handles brief per-minute bursts. It can't fix a spent daily budget. If you see 429s early in the day, you're probably hitting tokens per minute, so shorten your prompts or add pauses.
